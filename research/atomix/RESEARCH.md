## 核心对象，不把分子名误当成新道具

Atomix 的主要可交互对象是**带固定连接方向的原子**。元素、颜色和连接数是原子的属性，移动规则相同；原子不会因为相邻就自动粘住，也不会像 2048 一样合并成另一种原子。

| 对象／属性 | 初始外观 | 启动和持续动作 | 停止／碰撞 | 已实际验证 |
| --- | --- | --- | --- | --- |
| 空地 | DOS 棕色地面；网页白色空位 | 光标可通过；原子沿一行／列滑过 | 不会让原子中途停下 | 水关长距离滑动 |
| 固定墙 | DOS 不同关采用不同灰色金属纹理；网页金色凸块 | 无法选中移动 | 原子停在墙前一格，不破坏墙 | 水关、甲烷关、双键关 |
| H 氢 | DOS 蓝球；网页绿色 H 菱形及短连接柄 | 点选／Return 选中后四向滑行；柄随平移不转向 | 能给另一原子当挡块；不推走对方 | 两颗 H 在第一关多次互相挡停 |
| O 氧 | DOS 红球；网页红色 O | 与 H 相同；通常有两个固定方向连接 | 相邻后仍独立可移动；连接方向也要吻合 | DOS 水关的错误排列与正确排列；网页目标模型 |
| C 碳，多连接 | DOS 灰球带多条辐射柄；网页蓝色 C | 仍只四向移动；四个连接不代表能斜走 | 背景墙和原子阻挡与其他元素相同 | DOS 甲烷关 C 右边受阻，再下滑、上滑 |
| C 双键 | 网页柄有两条平行线，另有斜向单键 | 平移保留两条平行线的朝向 | 撞墙停住，不能把它旋转到另一侧 | 原作包第 4 关 Ethylen，C 向上滑 |
| C 三键 | 网页柄有三条平行线 | 与单键原子同样平移 | 停下后连接仍指向原方向 | 原作包第 29 关 Propyne，C 向左滑并撤销 |
| F 氟 | 网页紫红色 F，单个固定柄 | 四向移动，无“腐蚀”或射击特效 | 长距离滑行保持连接方向 | 第 21 关氟碳长链，F 向右滑；观察到中途帧，随后重置 |
| N 氮 | 网页黄色 N，包含斜向连接柄 | 连接可斜向，但移动仍四向 | 无旋转按钮；向上移动后柄方向不变 | 第 26 关 Ammonia，N 从中部滑到顶部 |
| 奖励彩块 | 彩色无字菱形 | 仍按滑动规则移动 | 靠颜色与相对位置组成目标图案 | 原作包第 6 关，粉块向下越过两格到墙前；Undo 恢复 |
| 目标模型 | 左侧小分子图／网页独立框 | 网页可拖动整个透明模型比对 | 不改变棋盘，不算移动次数 | kp-atomix 中从右侧拖到棋盘下方，再拖回；Moves 仍 0 |

**连接方向是胜负条件的一部分。**同样颜色的氢原子，如果一个柄朝左、另一个柄朝右，就不能随便互换它们在最终分子里的左右位置。相同元素、相同连接方向和数量的原子才可互换。

## DOS 原作的实际操作流程

1. 页面点真正的 “PLAY PC DOS GAME NOW”，加载 JS-dos；没有点击页面广告中的扩展安装按钮。
2. 出现爱因斯坦／ATOMIX 标题，Space 跳过，看到 PC 版署名和菜单。
3. 本次 PC 菜单用 `1` 选单人、`E` 选 Easy、`K` 选键盘，之后 Space 开始。
4. 第一关左侧显示 Player 1、Highscore、Level 01、Time 4:30、Molecule Water；目标为一排 H–O–H。棋盘全在屏幕内，不跟随滚动。
5. 方向键在未选原子时移动红色方框光标，**不是直接控制某个角色**。在原子上按 Return 才抓取，再按方向滑动；Return 再次释放。
6. Space 可以跳标题／开始，但本次键盘关内**不能用 Space 代替 Return 抓原子**。已实际试错并纠正；不能套用其他主机版的“fire=Space”。
7. 一次按左，第一颗 H 从上部通道右端滑到左墙前；一次按下，沿竖道滑到下部墙前，不需要逐格连按。
8. 选中状态跟着原子到新位置，可以继续转另一个方向；没有自动把“已相邻的一组”一起移动。
9. 光标能经过墙面位置，和原子碰撞规则不同。一次快速连发多键出现过漏输入；逐次观察后稳定。
10. 本次按 P 没有暂停计时：截图从 3:33 继续到 3:02。不能把 P 写成原作已验证的暂停键。
11. Easy 第一关超时：显示 “PLAYER 1 TIME OUT AND GAME OVER”；Space 到排行榜，再 Space 回标题。没有自动撤销或自动复原这关。
12. 键盘模式关内 Escape **直接退出到 DOS 提示符**，没有先出现确认框。手机实现不应照搬这个容易误退的交互。
13. 另试 `M` 鼠标模式，停在 “PRESS BUTTON”；浏览器点击、短拖和 Return 都没有推进。判断为这套模拟器的鼠标输入未正常送入，未报告鼠标模式可玩；重启改回 K 后恢复正常。

### 第一关：错误排列与实际通关

为了区分两颗看似相同的 H，把上方初始 H 记为 A，下方初始 H 记为 B，红色为 O。这只是研究记号，原游戏没有加字母。

- 初始 A 在上部、B 在下部、O 在右侧。
- 第一轮把 A、O、B 挤到底部同一排，三颗相邻，**没有过关**。按 Return 释放也没有过关，最后实际等到超时。
- 第二轮把顺序调整为 **B、O、A**，最后一颗滑到位后，原子开始逐个消失／爆散，进入下一轮 “PLAYER 1 IS ON MOVE / PRESS BUTTON”。
- Space 后实际看到 **Level 02 / METHANE / Score 3100 / Time 3:45**，这才是完成第一关的可靠证据；没有把三颗排在一起就当作已过关。
- 第二轮最后原子到位时余时约 2:40。爆散发生在移动结束后，不需要再释放才能结算。
- 原子形成目标的位置在棋盘底部，而小目标图在左侧：目标允许整体平移，**不要求在固定的一块地面上拼**。
- 第二关是 1 个中心碳、4 个氢的十字目标，墙块样式和场地轮廓都换了，证明后续不是单纯换一个分子名字。

研究中用转写自可见棋盘的坐标规划过路线，再通过真实键盘逐步执行。没有读取 DOS 内存、注入胜负或调用游戏内部函数。

## JavaScript 版的实际交互

### 点选与方向反馈

- 点原子后，只在能移动的方向显示金色三角箭头。例如右边紧贴墙时没有右箭头，不用试按无效方向。
- 点箭头，原子沿直线连续滑动，途中可以捕捉到非格中心的帧；完成后重新显示可走方向。
- 移动时连接柄随原子一起移动，**不会朝滑动方向转过去**。四向移动与八向连接必须分开画。
- 氟长链关的移动过程中点 Reset 可以重置场景；这不是“已经等到移动终局”的证据，记录为观察到中途运动后重置。
- Undo 回到移动前，Redo 回到移动后，Move 在 0→1→0→1 间正确改变；Reset Level 恢复初始布局及 Move 0。
- Save Level 链接的 URL 在移动后包含历史编码，撤销回初始后历史参数去掉。只核对链接，没有提交解法、姓名或创建浏览器书签。

### 可选关与后期内容

- Alan Draknek 的原作包下拉框实际列 **30 项**，含 6、12、18、24、30 五个 Bonus Section。实际跳过并操作：6 奖励、4 双键、21 氟链、26 氨、29 三键。
- 基础 kp-atomix 页的 KAtomic 包实际列 83 项，另有 original／pack1／mystery 包。83 项是这个重制包的规模，不能说原作有 83 关。
- Alan 的简化版在本次显示中没有独立目标预览，页内 “loading” 文本也仍留在辅助树；棋盘和选关实际可运行。基础 kp-atomix 页有完整目标框与移动计数，更适合作为触屏 UI 参考。
- 大关卡依旧全图显示，不是横向无限延伸世界。页面超高会滚动，所以不同关卡切换后截图的坐标需要重新读取。
- 第 26 关氨的 N 带斜向柄；第 29 关三键；第 21 关有多颗 C 与 F 的长链，后期复杂度来自布局、方向和停靠位置，不是新增重力／伤害物理。

## 动画与背景

### 实际看到

- DOS 标题为像素人物、金属字体和装饰框，关卡界面则以左信息区＋右棋盘为主；背景蓝斜纹，墙体主题随关改变。
- DOS 运动是连续滑动，不是瞬移；每个原子有高光／暗边，连接柄很小，初看容易误认相同。
- 完成分子后原子逐个爆散／消失，再切黑底回合提示；这轮没有看到大面积的物理爆炸或自由落体。
- JavaScript 版背景比较朴素，墙是凸起金块，原子用大字母提高可读性。目标模型拖动时有半透明框，明确是辅助模型而非真实棋子。

### 本项目应采用

- 手机不用移动光标再 Return；直接点原子，外圈高亮；方向按钮或滑动完成一次完整滑行。
- 每颗原子有元素字母与连接柄，1／2／3 条键要能分辨；柄至少覆盖上下左右与四个斜角。
- 目标图一直可见，并允许开启半透明比对模型，整体拖到任意可拼位置；移动比对模型不计步。
- 连接对上显示连接线，但原子继续独立移动；不要把它们自动合并为一整块。
- 允许撤销、重做、重开和选择关卡。默认无倒计时，先把挑战集中在空间规划；限时模式如加入应明确可选。
- 胜利短暂亮起正确连接，再显示下一关按钮，不要求输入昵称、联网提交或自动跳走。

### 源码辅助核查，不能代替实际试玩

- Atomiks `atomcore.c` 对完成分子扫描整体偏移，并比较具体原子编码，不只是元素颜色；与实玩中互换两种连接方向的 H 不过关相符。
- 30 份关卡文件中有 5 个奖励关；它们的标题和光标模式不同。数据存储用 16×16 容器，不等于每关实际可走区域都铺满 16×16。
- 资料明确区分引擎源码许可与原关卡／图像。这里仅研究并重新绘制图形、重新设计本项目关卡，没有复制这些素材或地图。

## 尚未声称完成的内容

- DOS 原作并未通关全部 30 项；只确认第一关通关、第二关的碳操作和一轮超时。网页跳关的高级对象操作不计作原关卡通关。
- 未逐一完成所有化学式与所有奖励图案；没有把分子名称数量当作动作覆盖数。
- 暂未原生操作 Mac／Windows／Linux 重制版；兼容性限制见上表。
- 未量化所有声音频谱、动画帧率或所有版本差异。实际交互、胜负和关键方向规则已经有实现依据。
