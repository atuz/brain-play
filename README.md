# 小小动脑场 · Brain Play

轻巧、适合手机的多语言益智小游戏合集。原生 HTML / CSS / JavaScript，零运行时依赖，不需要服务器或账号。

## 第一版游戏

- 2048／2584：3×3、4×4、5×5 棋盘，经典与斐波那契两种玩法；触屏滑动、键盘、方向按钮、撤销，各组合独立保存进度和最高分。经典 3×3 目标为 512，4×4／5×5 为 2048；斐波那契目标为 2584。
- 24 点：手机点选卡牌合并，逐张发牌和翻牌、双牌汇合动画、精确分数运算、撤销与原牌重来、当前局面的一步提示、过关反馈与本机记录。
- 水果连连看：最多两次转弯，支持棋盘外侧路径、提示、撤销、无可消组合自动整理；显示实际连接路径，提示同时高亮两个水果，整理保留空格位置。
- 消灭星星：点选一组预览得分，再点消除；真实下落及空列左移动画、剩余奖励、撤销。
- 熄灯：保证有解的随机棋盘、GF(2) 求解提示、撤销。
- 数字华容道：合法移动打乱保证有解；点按、滑动和箭头均按数字移动方向；真实滑动、目标小棋盘、撤销。
- 接水管：随机生成连通网络，旋转、漏口检测、提示及撤销。
- 迷你数织：原创 5×5 固定关卡，拖动涂色／标空、整笔撤销、线索完成反馈、下一关、每日挑战。
- 猜数字：四位互不重复数字，页面内数字键盘、选位修改、草稿恢复、A/B 翻牌反馈，不限次数。

进度、音效选项和记录仅保存在浏览器 localStorage 中；清理浏览器数据会删除这些记录。

## App 链接与语言

App 打开网站时，可把两位国家／地区代码放在 `country` 参数中，语言使用 `lang`：

```text
https://atuz.github.io/brain-play/?country=CA&lang=zh-CN#/
https://atuz.github.io/brain-play/?country=CA&lang=en#/game/twentyfour
```

- `country`：优先使用 App 链接中的有效代码，自动转成大写。没有时，从浏览器语言地区中读取，例如 `en-CA` → `CA`；浏览器未提供地区则留空。不会请求 IP 定位服务。
- `lang`：支持 `zh-CN`、`zh-TW`、`en`；顺序为链接参数 → 保存的语言 → 浏览器语言 → English。
- 参数放在 `#` 前。进入游戏、返回首页、切换语言都会保留国家码与其他查询参数；切换语言保留当前游戏进度。
- 设置中可手动修改国家码、语言、音效和动画；“自动”重新读取浏览器地区。

## iOS WebView 返回

App 链接增加 `app=1`，例如 `https://atuz.github.io/brain-play/?app=1&country=US&lang=zh-CN#/`。
网页也会自动识别原生注入的 `window.webkit.messageHandlers.brainPlay`，不依赖 User-Agent 猜测。

- 首页左上角显示“返回 App”；游戏页面保留返回小游戏首页的箭头，右上角的 × 返回 App。
- 网页通过 `brainPlay.postMessage({type: 'close', source: 'brain-play', version: 1})` 请求原生 pop；不会用网页历史模拟退出 App。
- 页面就绪发送相同结构的 `type: 'ready'` 消息。原生在收到可信页面的 ready 后隐藏备用返回栏；加载失败时恢复备用栏。
- App 只接受本站 `/brain-play/` 主页面发来的消息，其他来源和子 frame 不处理。语言设置、游戏切换会保留 `app` 参数。
- `app=0` 可以显式关闭网页的 App 导航；普通浏览器不会出现“返回 App”。

## 本地开发

需要 Node.js 20+ 与 Python 3。

```sh
npm run dev
# 打开 http://127.0.0.1:4173
npm test
npm run check
```

无 npm 依赖，无需 npm install。必须用 HTTP 服务打开页面，避免浏览器对 file:// ES modules 的限制。

## GitHub Pages

站点文件位于仓库根目录，所有资源使用相对路径，游戏使用 hash 路由，兼容项目子路径。
在 Settings → Pages 中选择 Deploy from a branch，然后选 `main` 分支的 `/ (root)` 目录。

## 设计与边界

单机游戏，提供简体中文、繁體中文与 English，键盘焦点、减少动画偏好与手机布局。首页只有游戏宫格和设置，规则收在游戏页面的帮助按钮中。语言、音效、动画和国家码只在首页设置中出现；游戏内齿轮只显示当前游戏支持的专属设置。不做联网排行榜或账号同步。
代码、图案和界面为本项目编写；没有引入第三方游戏代码和商业游戏资源。


## 手机交互验证（2026-10-20）

每个游戏都检查了触摸、撤销／重开、页面切换和多语言，新增移动轨迹及连续输入保护。`motion.js` 管理可取消动画，关闭动画或系统减少动态效果时直接呈现结果；切换游戏会取消残留动画和重开确认框。
