# 小小动脑场 · Brain Play

轻巧、适合手机的中文益智小游戏合集。原生 HTML / CSS / JavaScript，零运行时依赖，不需要服务器或账号。

## 第一版游戏

- 2048：触屏滑动、键盘、方向按钮、撤销、本机最高分。
- 24 点：保证有解的随机题，安全算式解析，答案校验、查看解法。
- 水果连连看：最多两次转弯，支持棋盘外侧路径、提示、撤销、无可消组合自动整理。
- 消灭星星：连通组消除、重力下落、空列左移、计分及剩余奖励、撤销。
- 熄灯：保证有解的随机棋盘、GF(2) 求解提示、撤销。
- 数字华容道：合法移动打乱保证有解，键盘与点击操作、撤销。
- 接水管：随机生成连通网络，旋转、漏口检测、提示及撤销。
- 迷你数织：原创 5×5 固定关卡，涂色与标空、撤销、每日挑战。
- 猜数字：四位互不重复数字，A/B 反馈，不限次数。

进度、音效选项和记录仅保存在浏览器 localStorage 中；清理浏览器数据会删除这些记录。

## 本地开发

需要 Node.js 20+ 与 Python 3。

```sh
npm run dev
# 打开 http://127.0.0.1:4173
npm test
npm run check
```

无 npm 依赖，无需 npm install。必须用 HTTP 服务打开页面，避免浏览器对 file:// ES modules 的限制。

## GitHub Pages

站点文件位于仓库根目录，所有资源使用相对路径，游戏使用 hash 路由，兼容项目子路径。
在 Settings → Pages 中选择 Deploy from a branch，然后选 `main` 分支的 `/ (root)` 目录。

发布后地址：https://atuz.github.io/brain-play/

## 设计与边界

单机游戏，提供中文规则、键盘焦点、减少动画偏好与手机布局。不做联网排行榜或账号同步。
代码、图案和界面为本项目编写；没有引入第三方游戏代码和商业游戏资源。
